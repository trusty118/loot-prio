BiS Rank Review

Every Wowhead BiS table, grouped the way the guide is written: one block per slot, with the author’s own sentence above it and all of its rows together — kept, alternate and dropped. A rank cell cannot be judged alone. Wowhead’s feral bear guide ranks Shadowmoon Destroyer’s Drape Threat Alternative, and the only way to know that means “not BiS” rather than “BiS for threat” is the sentence above the table naming two other cloaks as best.

Disagree with one? Click its id to copy — Arms/P3/32323 — and paste it back with what it should be. Decisions land in verify/rank-map.json, keyed per spec, because authors do not share a vocabulary.

What the columns and outcomes mean
#
The row’s position in the guide’s own table. Wowhead ranks by order, so row 0 is the author’s first choice. This is what decides which of several “Best” rows actually holds the slot.
Id
Spec, phase and item id. Click to copy, then paste it back to tell me a row is wrong. Stays valid if Wowhead reorders the guide.

What we did with it
One of:
phase · multi-phase · expansion — kept as a real BiS call. The word says how long it lasts, and it draws a purple, orange or gold ring on the site.
phase — the same, but the guide only ever called it best under a condition, so the ring is dashed.
alternate — the author offered it and said what for, but never called it best. Blue ring.
rank rejected — the rank is not a BiS call (Great, P2 Best, Best Pre-raid) or names no reason to offer it (Optional). The exact reason is under the label.
no such item — a different thing, and two-thirds of everything not shown. Wowhead ranks it but this site has no row for it, so there is nothing to put a ring on. Usually tier armour (what a token turns into), PvP, crafted or 5-man gear, which loot_data.json leaves out on purpose. The rank itself is often perfectly fine — the label says which.
A row marked P2 DROP
The guide for this phase ranks an item that drops in an earlier one, so it is not a row you can act on here — the site only ever shows that item under the phase it drops in. It is not noise, and deleting these would break the ring colours. How long an item lasts is derived from which phases go on listing it: Dragonspine Trophy is a Phase 1 trinket, and the only reason it wears a gold expansion ring is that the P2–P5 guides keep naming it. 1,057 of the 2,837 shipped entries are these.
