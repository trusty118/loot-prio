# Decisions


The reasoning behind `CLAUDE.md`, one file per area. `CLAUDE.md` says what *is*; these say *why*, including what was tried first and what it cost. Nothing here is required reading to work on the site - it is required reading before **changing** the thing it covers.

These were sliced out of `CLAUDE.md` verbatim in Sep 2026, so a `§2` or `§4` inside one of
them refers to the old numbering, not the current map. The material a `§` points at is in
the sibling file whose title matches.
